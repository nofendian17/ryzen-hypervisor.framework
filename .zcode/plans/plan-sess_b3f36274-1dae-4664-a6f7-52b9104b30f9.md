# AMDHV — rewrite sederhana RyzenHV untuk QEMU di Hackintosh AMD

## Context

RyzenHV saat ini (~13k baris) mendukung banyak target: Docker Desktop, Parallels, VirtualBox, VMware, shim dyld-interpose, patching memori klien, SwiftUI app, script-script bundling. Semua itu menambah kompleksitas, padahal jalur yang paling berguna untuk QEMU adalah **native mode**: kext mendaftar ke xnu sebagai penyedia Hypervisor.framework (via KPI publik `hv_set_traps`/`hv_set_callbacks` dari `hv_support_kext.h`) sehingga **QEMU tanpa modifikasi** (`qemu-system-x86_64 -accel hvf`) berjalan di atas AMD SVM, asal `kern.hv_support`=1.

Analisis menunjukkan dari ~8.570 baris kext, ~6.200 baris adalah mesin generik (SVM/VMCB/NPT/FPU/logging) yang sudah teruji di mesin Anda, dan ~2.350 baris (HvPatch + cabang HyperKit/Parallels di HvFrontend + tabel slot yang hanya untuk shim) ada murni untuk dukungan multi-app.

**Keputusan (sudah dikonfirmasi):** nama **AMDHV**, folder baru **/Users/beni/amdhv** (git repo baru), **native mode saja** (tanpa shim), strategi **port & sederhanakan core** — mempertahankan puluhan perbaikan bug yang sudah terbukti (FPU integrity, ensureThisCpu heal, TOCTOU, rescan late-CPU macOS 26, dsb).

## Yang dibuang (alasan)

- **HvPatch.cpp/.hpp (509 b.) + signing/decode-chain tests** — patching HyperKit + csrelax; QEMU tidak butuh patch klien.
- **Semua cabang HyperKit/Parallels di frontend**: `vm->hyperkit`/`vm->parallels` + deteksi nama proses, `parallelsCpuidFixup`, scrub CPUID HyperKit, skip APIC-page 0xFEE00000, hint "vcpu:<n>" dari stack, NMI-window shortcut, flight recorder/debug recording (~1.000 b.).
- **shim/ seluruhnya** (hv_shim.c, rhv_core.c, rhv_iokit.c, rhv_patch.c, hijack*.c, hv_stubs.inc, gen-hv-stubs.py) — ~3.900 b.
- **Selector VM di UserClient** (VmCreate/Run/RunEx/Map/…): jalur native mendaftar VM lewat trap langsung; UserClient tinggal diagnosa (GetInfo, ReadLog, SetLogLevel, GetStats, SelfTest, HvControl untuk sysctl/tpr/rescan).
- **app/ SwiftUI, release bundling QEMU, script Docker/Parallels, tools rhv-guest/map/vmx/long-test + patchcheck/hkpatch** (driver API raw userclient yang dibuang).
- **Boot-args**: `rhv_clientpatch`, `rhv_csrelax`, `rhv_vcpuhint`, `rhv_stage` bisect. Dipertahankan & di-rename ke `amdhv_*`: `-amdhv_off`, `amdhv_enable_svm=1`, `amdhv_hv=1` (register trap; **auto-flip `kern.hv_support` saat register** — QEMU membaca sysctl ini; toggle tetap ada via `amd-info hv sysctl 0|1`), `amdhv_tpr_shadow` (default on — QEMU memintanya lewat cap2ctrl), `amdhv_loglevel`, `amdhv_selftest`, `amdhv_allow_users=1` (untuk hvf-smoke non-root... tetap perlu root/entitlement; keep).

## Yang dipertahankan (inti teruji)

- **SvmRun.S** — jendela VMRUN (CLGI/VMSAVE/VMLOAD/STI+VMRUN/CLI/STGI). Satu-satunya assembly, port utuh.
- **Vm.cpp run loop** — VMRUN dengan interrupt off, swap FPU/XSAVE/DR0-3/TSC_AUX/CR2, timeslice 10 ms, kick IPI, absorb exit INTR/NMI, TPR-shadow fast path in-kernel, TLB flush per entry.
- **VmcsState/VmxMap** — emulasi VMCS di atas VMCB: applyControls (VMX→intercept VMCB), recordExit→translateExit (NPF→EPT violation 48 dengan qualification lengkap untuk QEMU), event injection, EFER.SVME hidden, CR4.VMXE shadow-only.
- **Npt.hpp** — NPT dengan pinning IOMemoryDescriptor + fallback read-only.
- **SVM.cpp** — probe/enableAll/ensureThisCpu/rescan/suspend/resume.
- **kCaps capability words** — tetap seperti sekarang (diketahui bekerja dengan QEMU), TPR shadow ditawarkan ke semua VM.
- **setSysctl/addressFromCode** — flip `hv_support_available` dengan verifikasi via sysctl OID (disederhanakan, tanpa flight recorder).
- **kern.hv_support & TPR shadow** via HvControl di UserClient untuk kontrol runtime.

## Langkah implementasi

1. **Scaffold**: `mkdir /Users/beni/amdhv && git init`, LICENSE (MIT, sama), .gitignore (build/, .DS_Store), README kerangka.
2. **Header bersama**: `include/AMDHVShared.h` (ABI v1, service `com_amdhv_AMDHV`, hanya diagnosa) + `AMDRing.h`; struct run internal (RHVRegs/RHVExit/RHVRunIn/Out) dipindah ke `kext/Source/VmInternal.hpp`.
3. **Port core** (langkah 2–3 file per commit): rename `rhv_`/`RyzenHV`→`amdhv_`/`AMDHV`, namespace `rhv::`→`amdhv::`, trim sesuai daftar buang di atas. Core murni (VMCB/VmcsState/VmxMap/MsrMap/Npt/FpuState/X86) nyaris verbatim.
4. **Frontend.cpp baru**: trap table (tVmCreate/Destroy, tVcpuCreate/Destroy/Run/Interrupt, tVmMap/Unmap/Protect, tVmSyncTsc, managed-MSR, tReadSlot/tSyncSpecial/tCapWrite), callbacks, slot marshalling (pakai HvSlots/HvMsrs), kCaps, TPR shadow, sysctl flip, register/unregister. Tanpa deteksi proses & tanpa fixup CPUID.
5. **UserClient diagnosa** + Info.plist: OSBundleLibraries **tanpa com.apple.kpi.private** (HvPatch hilang); kalau link hv_set_traps menuntutnya, tambah kembali minimal (dicek via check-kext-symbols.sh).
6. **Tests + Makefile root**: port 7 test murni, sesuaikan include; `make test` harus hijau dulu sebelum kext.
7. **Tools**: amd-info (subcommand: info/log/stats/selftest/hv), hvf-smoke (ubah pesan referensi shim→native).
8. **Scripts**: check-kext-symbols.sh, install-to-efi.sh (minimal: kext + boot-args `amdhv_enable_svm=1 amdhv_hv=1`), sign-qemu.sh, qemu-test.sh.
9. **Build kext**: `make kext` (port Makefile, rename output AMDHV.kext), jalankan check-kext-symbols; bereskan error link.
10. **README**: cara pasang di OpenCore, boot-args, `brew install qemu` + sign-qemu.sh, qemu-test.sh, batasan (16 vCPU/VM, sleep/wake untested, satu VM program), troubleshooting (`amd-info log`).

## Verifikasi

1. `make test` — 7 unit test murni (VMCS↔VMCB translation, NPT, MSR map, FPU/XSAVE, ring) hijau dengan ASan/UBSan.
2. `make kext tools` — build bersih; `check-kext-symbols.sh` lolos terhadap kernel yang berjalan.
3. Di mesin Hackintosh (langkah manual Anda, perlu reboot):
   - Pasang ke test EFI via `scripts/install-to-efi.sh`, boot dengan `amdhv_enable_svm=1 amdhv_hv=1`.
   - `sudo build/amd-info` → SVM aktif di semua core; `sudo build/amd-info selftest`.
   - `sudo build/hvf-smoke` → semua stage PASS (persis urutan panggilan QEMU: capability → controls → real-mode → IO/CPUID/HLT → EPT violation → hv_vcpu_interrupt).
   - `sysctl kern.hv_support` → 1 (auto-flip oleh kext).
   - `./scripts/qemu-test.sh` → Linux boot via QEMU stok `-accel hvf` tanpa DYLD_INSERT_LIBRARIES.
   - QEMU sendiri (Homebrew): `./scripts/sign-qemu.sh $(brew --prefix)/bin/qemu-system-x86_64` lalu jalankan VM Anda.

Repo lama tidak disentuh sama sekali — tetap sebagai referensi.
